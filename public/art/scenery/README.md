# 晨鐘美術素材

五份原創 image_gen 圖集，2026-10-28 文字生成。地標、陳設、地表、鐘亭試煉場、六種敵人的十八個姿態。不是 Square Enix、Sabotage Studio 或其他遊戲的素材。

generation.json 記錄來源圖識別、來源雜湊、發布檔雜湊、尺寸與用途。發布時只轉 WebP，保留透明通道；所有裁框、腳底定位、地板拼接、光影與攻擊效果由遊戲執行時繪製。source PNG 不是 app 的建置依賴。

行走人物仍使用 ../lpc/ 中逐檔署名的 LPC 美術；其原授權、署名和原始來源完整保留。地圖中使用該美術的組合作品仍須遵守對應 OGA-BY / CC-BY-SA 條件。這不改變應用程式原始碼的授權。
